Clinic alert thresholds

After you save these clinician-approved thresholds, the API server checks each incoming ESP32 reading against them. The ESP32 only needs to send its readings; it does not need to download the thresholds. SpO₂ and temperature are checked even if respiratory rate or activity is not sent. Alerts are rule-based prompts, not diagnoses. Email delivery separately requires SMTP settings on the server.
